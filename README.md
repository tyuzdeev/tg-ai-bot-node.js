# Node.js AI Agent (TypeScript + Telegraf + OpenAI Tools)

Продвинутый Telegram-бот, демонстрирующий концепцию ИИ-агента.

### 🛠 Stack: 
TypeScript, Node.js, Telegraf, OpenAI API.

### 🔥 Особенности:
* **Smart Routing:** Использование OpenAI Function Calling. Бот понимает контекст естественного языка (NLP) и динамически мапит намерения пользователя в вызов серверных JS-функций.
* **Type Safety:** Полностью типизированный код.
